Malformed interpreter tags are now rejected: `parse_tag` raises `InvalidTag` and `parse_wheel_filename` raises `InvalidWheelFilename` for names like `playlyfe-0.1.1-2.7.6-none-any.whl`.

**Complete**
- **`parse_tag`** (`src/packaging/tags.py`): each interpreter in the set must pass `str.isidentifier()`. The error reads, for example, `Tag '2.7.6-none-any' has an invalid interpreter: '2'`. ABI and platform rules are unchanged.
- **`parse_wheel_filename`** (`src/packaging/utils.py`): the message is now `Invalid wheel filename (invalid tag component): <filename repr>`, and the `InvalidTag` is chained as the cause. This message also replaces the old `empty tag component` wording for empty components, as requirement 3 implies.
- **Docs**: docstrings updated for `InvalidTag`, `parse_tag`, `InvalidWheelFilename` and `parse_wheel_filename`; short paragraphs added to `docs/tags.rst` and `docs/utils.rst`; a `CHANGELOG.rst` entry added under Fixes.
