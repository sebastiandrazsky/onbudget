# Third-party notices

onbudget's own code is MIT licensed (see `LICENSE`). The evaluation under `eval/` also contains code from eight upstream open-source projects: it appears in the runs' `ws.diff` files (the diff of what the model changed in a project's tree, with surrounding context lines) and in the task prompts. That code stays under its own licence. This file lists each project with its address and licence identifier, and gives the full text of its licence file or files, copied from the project's repository at the base commit of the task (the commit is linked in each entry, and `eval/TASKS.md` has the rest of the provenance). Nothing from these projects is relicensed by onbudget.

Notes on the copies. Line endings are LF throughout; the boltons `LICENSE` file uses CRLF in its repository, and the text is otherwise unchanged. The SHA-256 given with each file is that of the file as stored in the repository. None of the three Apache-2.0 projects (Falcon, Tenacity, packaging) has a `NOTICE` file at the base commit. Werkzeug appears in two tasks (`werkzeug`, `werkzeug-cond`); its licence file is identical at both base commits.
