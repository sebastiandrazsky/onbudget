I finished five of the seven tasks. Each of those five passes its full offline suite. I didn't start falcon or werkzeug-cond because there wasn't enough budget left to do them properly.

- **pluggy**: when a hook call passes a value, every hookimpl now gets it, even one that declares its own default. Otherwise the hookspec default is used, and the hookimpl's own default only when neither applies. This covers plain hookimpls, `wrapper=True` and `hookwrapper=True`. I added the docs section and `changelog/442.bugfix.rst`. The `versionchanged` note says 1.7; that's my guess at the next release, so check it. One existing test, `test_does_not_override_hookimpl_default`, asserted the old behaviour (its docstring said it was "not necessarily what we want (#442)"), so I renamed it and changed it to assert the new order. 199 passed.
- **boltons**: all six bugs are fixed. One extra fix: `Table([[]])` crashed in the constructor before `to_text()` was ever reached, so I fixed that too. `daterange` now checks the step when it's called, not on first iteration, so a bad step raises `ValueError` right away. `xfrange` gives the same output as `frange` on a grid of float cases. 446 passed.
- **markdown-it-py**: added `MD_TRIM_CHARS`, `mdTrim` and `MD_TRIM_RE`, and switched headings, setext headings, paragraphs, table rows and cells, fence info and `normalizeReference` over to them. I checked by hand that the five characters survive in each case and that `[a b]` no longer matches `[a\x85b]`. 1016 passed.
- **pydantic-settings**: collection detection now accepts any subtype of `Sequence`, `Set` or `Mapping`, bare or parameterized, including inside `X | None`, but not `str`, `bytes` or `bytearray`. I checked by hand:
  - variadic tuple, frozenset and `OrderedDict` options and positional arguments;
  - repeated plain options for tuple, frozenset, deque and bare `tuple`;
  - `key=value` input for `OrderedDict` and `MutableMapping`;
  - the new error message.

  The docs are updated, and one test's expected error message was changed to match. 655 passed, 68 skipped.
- **werkzeug (ETag)**: added the `ETag` class and the `Response.etag` property, renamed `ETags` to `ETagSet` (the old name warns), and deprecated `get_etag`, `set_etag`, `quote_etag` and `unquote_etag`. All internal callers use the new API now, the tests are moved to it, and `CHANGES.rst`, the datastructures docs and the quickstart example are updated. 988 passed with warnings treated as errors.
